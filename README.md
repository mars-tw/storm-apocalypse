# 暴風啟示錄 Storm Apocalypse

雪地末世「放置經營 × 塔防」3D 網頁遊戲 MVP。玩家在牧場獵牛取肉，搬回肉舖販售，再用收入建造弩塔，守住三波殭屍夜襲。

## 啟動

```bash
npm install
npm run dev
```

正式建置：

```bash
npm run build
npm run preview
```

## 操作

- `WASD`／方向鍵：移動
- `Space`／`E`／右下攻擊鍵：揮砍
- `B`／右上建造鍵：資金足夠時建造弩塔
- `N`／畫面下方波次鍵：啟動夜襲
- 手機：左下觸控搖桿移動、右下攻擊鍵揮砍

資金、已完成波數、攤位等級與弩塔建造狀態會儲存在瀏覽器 localStorage。
