# Storm Apocalypse Roadmap

## 本輪 MVP：已完成

- Babylon.js 低多邊形雪地場景：程序起伏地形、風蝕雪材質、遠山、霧、動態日／夜色調。
- DirectionalLight、HemisphericLight、PointLight、PCF 陰影、FXAA、柔和 bloom。
- 42 棵共享來源松樹、岩石、木柵欄、模組化雪屋、營火與兩層飄雪粒子氛圍。
- 第三人稱斜俯視跟隨鏡頭；夜襲時自動拉遠並切換暗藍環境。
- Quaternius 動畫玩家：WASD／觸控搖桿移動，`Run / Idle / Slash` clip 切換。
- 動畫牛：吃草、巡遊、受擊、死亡、掉落三份肉、九秒後重生。
- 肉品拾取與背包視覺堆疊；靠近攤位自動陳列。
- 動畫顧客沿雪徑到店、購買一份肉、付款 20 元、離場。
- 一種可建造防禦塔「獵風弩塔」，會追蹤目標並發射實體箭矢。
- 動畫殭屍三波：行走、攻擊、受擊、死亡；肉舖有 100 點壁壘生命。
- 三波 MVP 勝利／失敗結算、資金與進度 localStorage 儲存。
- HTML/CSS HUD、引導目標、Toast、桌機與手機 RWD、觸控攻擊鍵。

## 下一階段：Alpha（30 波完整戰役）

1. 將三波驗證擴展成 30 波曲線，加入菁英怪、胖殭屍、爬行者與 Boss。
2. 波次間加入 60–90 秒經營白天；預告下一波抗性與推薦塔種。
3. 存檔 schema 加版本遷移、離線收益時間戳與手動重置確認。
4. 用共享骨架／crowd manager 擴展到 40–60 隻同屏殭屍，加入行動裝置品質分級。

## 武器升級

- 砍刀：目前的單體近戰，補完命中特效與音效。
- 迴旋斧：360° 範圍橫掃、擊退、蓄力冷卻環。
- 衝鋒槍：遠程射線／彈道、彈匣、換彈與自動瞄準輔助。
- 加入武器桌、可視化模型替換、傷害／攻速／暴擊三條升級線。

## 自動化員工

- 獵人：尋路進牧場、攻擊、搬運；可升攻速與容量。
- 收銀員：縮短顧客結帳時間並提高小費機率。
- 牧羊犬：優先撿取即將消失的肉；以 Quaternius 動畫犬模型呈現。
- 加入薪資、休息與暴風士氣，使放置經營不只是數值加速。

## 擴張與防禦塔

- 攤位 2–4 級：增加可陳列格與同時服務顧客數。
- 新牧場：野牛／鹿，生命更高但肉品單價與品質更高。
- 砲塔：慢速範圍爆炸、地面灼痕與震動。
- 冰塔：降低移速、疊層凍結、與砲塔產生碎冰連鎖。
- 塔的升級分支、出售、移位與建造預覽；加入障礙與正式導航網格。

## 美術與聲音

- 冰湖反射、雪地足跡／血跡 decal、被風吹動的旗幟與屋頂積雪變化。
- 暴風環境音、腳步材質音、武器／塔／殭屍 Foley、分層戰鬥音樂。
- 補上設定選單：音量、色弱模式、陰影與粒子品質、鏡頭震動強度。
- 商店頁攝影模式：隱藏 HUD、自由鏡頭與 4K 截圖。

## 目前已知缺口

- MVP 刻意只做 1 種塔與 3 波；箭塔／砲塔／冰塔完整三種仍在下一階段。
- 尚無武器購買、員工、攤位擴容與新牧場 UI；資料欄位已為攤位等級保留。
- 目前同屏敵人數少，採每個動畫角色獨立骨架；30 波版需切換共享骨架或 crowd 策略。
- 尚未加入音效、PWA、localStorage 本地排行榜與無障礙重新綁鍵。
- 手機已做操作與效能縮放，但仍需在實體中低階 Android／iOS 長時間壓力測試。
