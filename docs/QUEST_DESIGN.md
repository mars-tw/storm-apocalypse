# 《暴風啟示錄》任務設計：生存手冊

## 設計目標

「生存手冊」是貫穿 30 波戰役的單一路徑主線。前五章在不打斷操作的前提下教會狩獵、搬運、陳列與收銀；中段引導玩家把收入轉成員工、牧場、武器與塔；最後以自動化、塔升級和 30 波破關收束。任務自動追蹤、自動領獎，不要求玩家再按一次確認。

左側手冊同時只顯示一個主線章節，包含章號、標題、北境日誌、`目前值 / 目標值`、進度條及獎勵預覽。完成時先播放打勾與金光，再滑入下一章；夜襲時在其下顯示一個循環小任務，讓等待塔輸出時仍有可主動追求的目標。

### 進度與解鎖原則

- 指標採終身累計；先完成後才走到該章的玩家不必重做，例如已雇齊員工時抵達第 12 章會直接結算。
- 解鎖採溫和硬鎖：商店保留所有項目可見，未解鎖項顯示「🔒 完成手冊第 X 章解鎖」，UI 與購買邏輯都會攔截。第 5 章開放塔建造、第 6 章開放員工、第 7 章開放牧場 2、第 8／9 章依序開放斧／SMG、第 10 章開放塔升級。這讓教學節奏不會被先買後認證打亂，同時讓玩家預先看見後續目標。
- 舊存檔相容採「不回收」原則：已持有的武器、員工、牧場與塔照常保留；只有尚未取得的新購買／升級會受章節門檻限制。
- 金錢獎勵進入同一份經濟存檔；解鎖與徽記保存於任務狀態。
- 一次狀態更新最多連續結算數章，但每章的完成動畫與提示依序播放，避免獎勵訊息重疊。

### 經濟定位

經營是主要收入，戰鬥是守住生產線並提供補貼。肉品單價由 20 起，收銀員與牧場 2 各增加 5，讓中期投資直接提高每筆交易價值。擊殺賞金壓低為行屍 2／奔行者 3／蠻屍 5／Boss `25 + 波次`；清波獎金為 `16 + min(波次, 10) × 3 + max(波次 - 10, 0) + Boss 波 35`。後十波仍有成長，但斜率由前段每波 3 降為每波 1，不再讓戰鬥收入快速壓過肉舖。

## 循環小任務

每波開始時，依波次編號輪替指派一項；同一波重新整理後，若原任務在新的開波條件下仍可行，便保留原任務與進度；若空貨架等 session 重置使條件失效，會重選可行題。已領獎任務永遠保留，不能藉重整同波再領。任務完成立即給獎且只給一次。若該波結束仍未完成，顯示「未達成」後由下一波換題。

| 任務 | 達成條件 | 獎勵與縮放 |
|---|---|---|
| 完整貨架 | 開波時有存貨、且該波確有蠻屍／Boss 偷貨威脅；結束時沒有存貨遭奪 | 20 + 波次 × 2 |
| 箭雨校準 | 本波由防禦塔擊殺 `3 + floor(波次 / 3)` 隻 | 20 + 波次 × 3 |
| 親手清場 | 本波由玩家擊殺 `2 + floor(波次 / 5)` 隻 | 25 + 波次 × 3 |
| 不退防線 | 第 4 波後具奔行者威脅時，結束壁壘生命不低於 75% | 25 + 波次 × 2 |
| 寒霜驗證 | 寒霜塔累計命中 `5 + 波次` 次 | 20 + 波次 × 2 |
| 爆破紀錄 | 實際敵數至少 18 時，火砲一次爆炸命中至少 3 隻 | 35 + 波次 × 2 |

任務會檢查可行性：尚未建造寒霜塔／火砲塔時不派對應任務；擊殺目標以該波實際敵人數封頂；空貨架或沒有偷貨敵種時不派「完整貨架」；低密度波不派「爆破紀錄」。輪替以六題固定順序向後尋找第一個可行項目，不會因新建塔改變同波 modulo。玩家和塔擊殺以傷害來源記錄，不用猜測最後一擊。

## UI 與互動規格

- 手冊面板：桌機寬 304px；手機預設收合成頂部「手冊 章號 · 進度」小條，點開後寬度不超過安全區可用寬；平板維持收合面板但 HUD 回到單列中間版面。
- 進度條：數值變化以 250ms 寬度轉場；數字使用等寬數字。獎勵預覽固定放在進度條下方。
- 完成：面板套用 700ms `quest-complete` 動畫，章號變成勾號，獎勵以 Toast 入帳；下一章從左側滑入。
- 循環任務：只在波次進行中展開；完成後保留綠色勾號直到該波結束。
- 觸控：標題與情境提示改顯示虛擬搖桿、揮砍鈕與整備入口；手冊／整備小條至少 48px 高，其餘商店、塔選擇、塔升級、波次與攻擊按鈕的可點區均至少 44×44px；面板內容可垂直捲動。
- 安全區：頂部 HUD、側面板、底部搖桿／攻擊均納入 `safe-area-inset-*`；390px 手機把開波鈕移到雙手控制上方，避免與搖桿重疊；1024px 觸控平板使用單列 HUD 與較寬面板的中間版面。
- 行動效能：行動 UA、1024px 以下觸控裝置或低記憶體／低核心數裝置自動選低畫質；以穩定 30 FPS 為最低目標，低檔降低硬體解析度、陰影、粒子與後製成本。
- 動畫遵守 `prefers-reduced-motion`，關閉位移與脈衝，只保留狀態色。

## 資料與存檔

存檔鍵維持 `storm-apocalypse-save-v1`，資料加入 `version: 2`，避免讓已上線玩家失去進度。載入流程為：解析 → 驗證數值／列舉 → v1 遷移 → 以預設值補欄位 → 儲存 v2。

任務永久資料：目前章節、已完成章節、解鎖旗標、循環任務（ID、所屬波、進度、目標、是否領獎）及終身統計。`totalEarned` 表示所有正收入；既有存檔至少以「目前資金－開局資金」補出保守下限，避免富有舊檔卡在第 6 章。波內暫態資料記錄玩家／塔擊殺、寒霜命中、砲擊最大命中、開始時庫存與壁壘最低值。

v1 遷移規則：保留 `money / wave / stallLevel / towerBuilt / bestWave`；`towerBuilt: true` 轉為獵風弩塔 1 級；舊波數直接映射到主線波次統計；無法由舊資料證明的狩獵／交易指標從 0 開始。壞資料、負數與未知列舉回退到安全預設，不讓載入中斷。

## 驗收條件

1. 15 章可依實際遊戲事件推進，進度、獎勵、文案與解鎖均可見。
2. 六種循環任務能依塔持有狀態派發，重新整理不重複領獎。
3. v1 存檔能載入且原有弩塔、資金與波次保留；壞 JSON 回復預設。
4. 桌機與 360px 寬觸控版不遮住主要操作，互動目標至少 44px。
5. 第 30 波完成時先結算最後任務，再顯示完整戰役統計與重開選項。
