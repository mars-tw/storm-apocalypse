# 暴風啟示錄全面優化計畫 R12

輪次代號：storm R12  
基準版本：0.2.3  
目標版本：0.2.4  
依據：`docs/AUDIT_full.md`、`AGENTS.md`、`game-optimization-round` 八大面向與固定品質閘門

## 本輪目標

R12 先處理審計 P1 與固定技能清單的交集：補齊全遊戲聲音回饋與玩家可控設定中樞，修正壁壘生命重載回滿的存檔漏洞，並用可讀事件波打破後期公式化節奏。所有新增介面必須在 1366×600、1280×640、手機直向與手機橫向可見可點；現有 R8/R10 角色與真動畫管線只驗證、不以單圖位移或晃動替代。

## 八大面向逐項計畫

### 1. 美術

現況：R8/R10 角色與 UI 美術已成形；審計確認唯一穩定 console error 是缺少 favicon。雪地已有主題素材，但地表層次仍可加強。

本輪項目：

- 新增 repo 內自製 favicon 並在 `index.html` 明確引用，移除 `/favicon.ico` 404。
- 在不增加外部授權素材的前提下，為雪地補一層低成本色帶/霜痕/風雪細節；低畫質仍可關閉額外細節。
- 保存 3 個視口的 before/after 證據到 `docs/evidence/R12/`。

驗收：

- headed 瀏覽器 console error 為 0，favicon 請求成功。
- 雪地新增細節不遮住互動標記、建塔點或角色，且低畫質不增加不必要 draw call。
- 1440×900、1366×600、390×844 截圖可辨識修改前後。

### 2. 按鈕

現況：R11 既有 HUD 控制已通過補充可達性檢查，但缺少設定入口。

本輪項目：

- 在 HUD 加入齒輪小圖示設定鈕，使用可讀 `aria-label`/title 並保留清楚 focus 樣式。
- 新增暫停/設定面板內的繼續、分頁、音量/靜音、畫質、震動、重置存檔與確認/取消控制。
- 擴充控制可達性守門，納入新按鈕與 1366×600、1280×640、390×844、844×390。

驗收：

- 所有新控制的 hit target 至少 44×44px，中心點可命中自身、互不重疊、不被浮層遮擋。
- 設定鈕在所有目標視口都位於 viewport 內；鍵盤可用 Tab/Enter/Space 操作，Esc 可開啟/關閉。
- modal 任何分頁均可由固定可見的關閉/繼續鈕離開。

### 3. 選單

現況：沒有暫停/設定中樞；手冊與整備不能代替系統選單。

本輪項目：

- 建立暫停 overlay，開啟時停止遊戲模擬與戰鬥輸入，關閉後安全恢復。
- 採「遊戲／聲音／系統」分頁；面板內容限制在畫面內，不以長捲動承載所有設定。
- 聲音分頁：主音量、效果音量與靜音。
- 遊戲分頁：畫質自動／高／中／低、螢幕震動開關。
- 系統分頁：重置存檔入口，使用二次確認，取消後回到原頁且不誤刪資料。
- 設定寫入 localStorage，重載後保留。

驗收：

- 1366×600 與 844×390 無頁面長捲，分頁/關閉/確認控制始終可見。
- 暫停時 wave、敵人、冷卻、玩家動作不前進；恢復後無時間跳躍或重複命中。
- 重置必須先確認；取消不改存檔，確認才清除並回到乾淨首玩狀態。

### 4. 人物

現況：R8/R10 三主角與 NPC 已符合有臉、辨識剪影、配色與 64px 可辨識要求；本輪不重做素材。

本輪項目：

- 重跑既有角色資產/縮圖檢查，確認 R12 UI、畫質切換與暫停不改壞角色載入或材質。
- headed 截圖抽驗三主角選角與遊戲內角色。

驗收：

- 三主角模型、立繪與 64px 縮圖可載入，臉部與剪影未回歸。
- smoke 既有 R8/R10 角色契約全綠，runtime 不退回 legacy 角色。

### 5. 地圖模型

現況：雪地、松樹、岩石、柵欄與雪屋主題完整，但素材來源混搭且雪地可再增加前中後景層次。

本輪項目：

- 以現有材質/程序化 shader 參數補雪地微弱色差與風雪層次，不新增占位方塊或未授權模型。
- 驗證品質檔位：高／中保留層次；低檔可裁減裝飾但不得換成方塊素體。

驗收：

- 地圖仍為真雪地題材，建塔點與敵我輪廓對比清楚。
- 品質切換可即時生效，沒有材質錯誤、黑模、地面閃爍或新增 404。

### 6. 技能

現況：技能圖示、冷卻與命中幀邏輯已有；最大缺口是施放/命中缺少聲音回饋。

本輪項目：

- 建立零外部資產、可延遲初始化的輕量 WebAudio 系統；所有 AudioContext 都由首次使用者手勢解鎖。
- 程序化合成揮砍、命中、建塔、售肉、波次開始、Boss 登場、倒塔警報、UI 點擊音；依事件而非輸入意圖觸發。
- 攻擊揮砍在動作開始/揮動階段播放，命中音只在 active impact/hitbox 真正命中時播放；揮空不得播放命中音。
- 音量、效果音量、靜音設定即時套用並保存。

驗收：

- smoke 可攔截/偵測八類音效事件，命中音不在按下攻擊當下誤觸發。
- 靜音後不產生可聽輸出，解除靜音與音量調整立即生效；未解鎖或不支援 WebAudio 時遊戲仍可玩且無 uncaught error。
- 無外部音訊資產與授權負擔；`CREDITS.md` 記錄為 repo 自製程序化音效。

### 7. 腳色樣子

現況：R8/R10 已通過角色亮度、飽和度、三視圖與頭部存在檢查。

本輪項目：

- 重跑亮度＋飽和度雙閘門與模型動畫資產契約，不調整已通過的主角造型。
- 對三主角正／側／背資產證據做存在性回歸核對。

驗收：

- 亮度 0.30–0.75、近黑像素 <35%、飽和度 ≥0.32、低飽和像素 <20%。
- 三視圖與頭部存在檢查通過；角色不蒼白、不過暗、不方塊化。

### 8. 動作流暢度

現況：AGENTS 動畫契約與 R8/R10 smoke 已確認玩家、Boss、員工/顧客/牧羊犬使用骨架/clip；傷害在 impact 時點解析。

本輪項目：

- 保持 physics root/collider 與視覺動畫分離，不更換現有真動畫管線。
- 擴充回歸斷言：攻擊 anticipation／impact／recovery 完整、傷害只在 impact/active hitbox、揮空零傷、敵人 hurt/death 播放、低效能檔仍使用 clip。
- 暫停期間凍結動作狀態，恢復後延續而非跳過命中幀。

驗收：

- 既有動畫 smoke 全綠；不出現以單張角色圖片位移、旋轉、縮放或 bobbing 冒充走路/攻擊/受傷/死亡。
- headed 實測暫停於戰鬥中再恢復，不會提前扣血、重複扣血或略過 recovery。

## P1 遊戲流程修正

### 壁壘生命存檔

- 將 `baseHealth` 納入版本化存檔，載入時正規化為合法範圍；舊存檔沒有欄位時只遷移一次為 100。
- 所有扣血、波後修復與重置路徑都寫回存檔，重載不得回滿。

驗收：壁壘降到指定血量後存檔並 reload，生命保持一致；波次開始既有修復只增加規則定義的數量且不超過 100。

### 事件波導演

- 在既有 30 波公式上增加資料化變化事件，至少包含可讀的「暴風突襲」與「精英壓境」類型，改變出生節奏/組成而非只加文字。
- HUD/波次預告顯示本波事件，Boss 登場有獨立聲音與提示。

驗收：smoke 固定檢查至少兩種非 Boss 事件波的資料、規則差異與 UI 預告；一般波與 Boss 波仍可完成。

## 素材與授權策略

本輪音效一律由 WebAudio oscillator/noise 即時合成，不引入外部音檔；favicon 與雪地細節由 repo 內程式/向量自製。若實作過程發現既有動畫或模型資產缺件，必須在報告列出缺件與可替換介面，不以單圖晃動假報完成。
