| 欄位 | 內容 |

---

## 0. 設計目標與邊界

### 0.1 目標

1. **可選主角 ×3**：開局三選一，人設一句話＋一個明確開局被動；選擇寫入存檔並影響整局節奏。
2. **具名 NPC 顧客 ×4**：常客有名字、偏好與好感階，收集好感解小獎勵，強化「肉舖人情味」。
3. **員工升級線**：獵人／收銀員／牧羊犬各 **Lv1→Lv2**（雇用＝Lv1，再買一級＝Lv2），延續中後期經營感。
4. **Blender 低模規格**：配色、輪廓特徵、預算與腳本命名，供後續 `tools/blender/*.py` 建模。

### 0.2 非目標（本文件不做）

- 不新增第四種員工、不擴充武器樹、不重做 15 章主線。
- 不引入複雜對話樹、分支結局、戀愛系統或好感衰減。
- 不要求完整面部 blendshape／高模；維持純色 PBR、flat shading、程式化低模風格。
- **本輪只寫規格，不改 `src/`、不改存檔 runtime、不建模。**

### 0.3 與現況對齊的假設

| 現況 | 本設計如何銜接 |
|---|---|
| 玩家模型共用 `survivor.glb` | 主角三選一改載專屬 GLB（或共用骨架＋外觀置換）；過渡期可用色票／配件區分 |
| 顧客單一 `customer.glb` 循環 | 具名 NPC 以「優先佇列／權重」插入顧客流；未解鎖時仍用匿名顧客 |
| 員工 boolean 雇用 | 升級為 `employees: Record<EmployeeId, 0\|1\|2>`（0＝未雇） |
| 肉價 `20 + 收銀5 + 牧場2的5` | 主角被動與好感獎勵疊加時需有上限與文案透明 |
| 存檔 `version: 2` | 本功能建議升至 **v3**，v2 遷移時主角預設「屠夫老闆娘」、員工 `true→1`、好感全 0 |
| 角色 tris 預算（Boss 先例） | 可動角色 **&lt; 800 tris**；靜止半身／招牌可放寬至 300 |

## 1. 可選主角 ×3

### 1.1 體驗定位

| 主角 | 玩法偏向 | 適合誰 |
|---|---|---|
| 屠夫老闆娘 | 經營加速（肉舖金流） | 想先堆經濟、快雇員工／建塔 |
| 退伍狙擊手 | 戰鬥偏向（武器傷害） | 想親自清場、循環任務「親手清場」 |
| 機械師少年 | 防線偏向（塔費折扣） | 想早建三塔、升塔到 3 級 |

三條路線皆可通關 30 波；差異在**節奏**而非硬性鎖關。教學章（Ch1–5）不因主角改變目標文字，只在 HUD 顯示被動圖示與數值提示。

### 1.2 主角表

| ID | 顯示名 | 一句人設 | 開局被動 | 被動公式（規劃） | 視覺關鍵字 |
|---|---|---|---|---|---|
| `butcher_matron` | **屠夫老闆娘** | 封鎖區紅燈下仍堅持掛秤的女人——「沒秤就沒公道，沒公道就只剩搶。」 | **賣肉 +10%** | 每筆肉品交易收入 `floor(baseIncome × 1.10)`；`totalEarned` 同步以實際入帳計 | 圍裙血漬紅、秤錘、厚肩外套 |
| `vet_sniper` | **退伍狙擊手** | 放棄長鏡後改握砍刀的哨兵——「子彈會用完，但準星還在腦子裡。」 | **武器傷 +1** | 所有玩家武器每次命中結算 `damage + 1`（砍刀 2→3、斧 3→4、SMG 每發 2→3） | 軍綠罩衫、單側護目、彈藥袋空掛 |
| `mech_youth` | **機械師少年** | 把廢鐵焊成塔的小鬼——「齒輪比人誠實，轉不動就換。」 | **塔費 -10%** | 建造與升級塔的花費 `ceil(listPrice × 0.90)`；武器／員工／牧場價格不變 | 護目鏡上額、工具腰帶、補丁外套 |

> 使用者範例被動（賣肉+10%／武器傷+1／塔費-10%）已採納為正式數值錨點。

### 1.3 選角流程（UI／狀態）

```
[新戰役] → 選角畫面（三卡並排）→ 確認 → 寫入存檔 → 進入 Ch1 場景
[讀檔]   → 若已有 protagonistId → 跳過選角
[重置進度] → 清空存檔後重新選角
```

**選角畫面規格（規劃）**

- 三張角色卡：立繪／低模半身、一句人設、被動徽章、一句「這局會變什麼」。
- 預設游標／焦點在 **屠夫老闆娘**（最貼近「肉舖經營」主敘事）。
- 確認前可來回切換；確認後**本局不可換角**（避免存檔與經濟重算複雜度）。
- 行動裝置：直向可垂直滑動三卡；觸控目標 ≥ 44×44px；確認鈕 ≥ 48px 高。
- `prefers-reduced-motion`：取消卡片浮入，只保留焦點框色。

**文案範例（卡面副標）**

| 主角 | 副標 |
|---|---|
| 屠夫老闆娘 | 這局：肉舖更快堆出第一座塔 |
| 退伍狙擊手 | 這局：你的刀與槍更疼，守夜更像獵人 |
| 機械師少年 | 這局：三角防線比較不傷本 |

### 1.4 存檔欄位（規劃 v3）

```ts
// 概念型別，非本輪實作
type ProtagonistId = "butcher_matron" | "vet_sniper" | "mech_youth";

interface SaveStateV3 {
  version: 3;
  // ...既有欄位
  protagonistId: ProtagonistId; // 必填；新檔於選角後寫入
  // 員工改級距，見 §3
  employees: Record<EmployeeId, 0 | 1 | 2>;
  // 常客好感，見 §2
  customerAffinity: Record<NamedCustomerId, number>; // 0..max
  customerRewardsClaimed: string[]; // 獎勵節點 ID
}
```

**遷移規則（v2 → v3）**

| 來源 | 目標 |
|---|---|
| 無 `protagonistId` | 預設 `butcher_matron`（不強逼玩家重選，避免中斷進行中戰役） |
| `employees.hunter === true` | `employees.hunter = 1`（其餘員工同理；`false` → `0`） |
| 無好感欄位 | 全 0、已領獎勵 `[]` |
| 壞字串／未知 ID | 回退 `butcher_matron` 與員工 0，不中斷載入 |

可選 UX：讀取舊檔時 Toast「已套用預設主角：屠夫老闆娘（可於新戰役重選）」。

### 1.5 數值平衡備註

- **老闆娘 +10%**：在底價 20（無收銀／無牧場 2）時約 +2 金／筆；有收銀與牧場 2 時底 30 → 入帳 33。屬溫和經濟加速，避免碾壓任務獎勵。
- **狙擊手 +1 傷**：前中期砍牛與清小屍體感明顯；對 Boss 有幫助但不取代塔輸出主軸。
- **少年 -10% 塔費**：三塔 Lv1 原價 60+110+160＝330 → 約 297；單一塔升滿（示意）亦約省 10%。不折扣員工／武器，避免「全店打折」。
- **互斥**：主角被動不互相疊加（一局僅一角）。
- **夜襲禁購**：塔費折扣只影響實際扣款，不改變夜襲中禁止購物規則。
- **顯示**：商店價格列應顯示折後價（少年）或「被動已套用」小標，避免玩家心算。

### 1.6 敘事接點（輕量）

- 開局 Toast 依主角換第一句日誌（不改 15 章標題）：
  - 老闆娘：「秤要準。今天的肉，還有人等。」
  - 狙擊手：「風向不對。先保住燈，再談子彈。」
  - 少年：「塔架歪了半指……我先焊，你們先撐。」
- Ch7「第一位同伴」、Ch12「無人也能運轉」文案通用，不依主角分支。

### 1.7 驗收條件（實作後）

1. 新戰役必經選角；確認後 `protagonistId` 持久化，重整頁面仍保留。
2. 老闆娘每筆賣肉入帳為 +10%（含顯示與 `totalEarned`）。
3. 狙擊手所有武器命中傷害 +1（含 UI 武器說明可選顯示）。
4. 少年建塔／升塔扣款為 90% 進位規則一致。
5. v2 存檔可載入並遷移，不丟資金／波次／任務進度。

## 2. 具名 NPC 顧客 ×4

### 2.1 設計意圖

現況顧客是匿名循環單位（到店→買一份肉→離場）。加入 **4 位常客** 後：

- 玩家認得出「又是老周來了」；
- 用**偏好**給經營微策略（陳列／時機／被動協同）；
- 用**好感階小獎勵**補中期爽感，但不變成第二套主線。

### 2.2 常客表

| ID | 名字 | 身份一句 | 偏好 | 到店行為差異 | 好感觸發 |
|---|---|---|---|---|---|
| `lao_zhou` | **老周** | 封鎖線外還在收廢鐵的瘸腿收購商 | **好肉／份量感**：交易時若玩家已雇收銀員，額外滿意（好感 +1 額外判定） | 走路偏慢；結帳後常咕噥「夠秤」 | 完成購買 +1；有收銀員時再 +1（每日／每波上限見下） |
| `nurse_lin` | **林護理** | 臨時醫務帳篷的夜班，用肉換人清醒 | **穩定供貨**：開波前貨架有肉時更常出現 | 傍晚／夜襲整備期權重↑ | 購買 +1；若當波開始時 `displayedMeat ≥ 2` 則購買 +2 |
| `kid_bao` | **小包** | 躲在雪屋後的孩子，付錢總是硬幣與扣子混著 | **便宜／人情**：底價交易也滿足；老闆娘在場時對話變溫 | 較矮碰撞盒；離場跑較快 | 購買 +1；主角為老闆娘時再 +1 |
| `scout_he` | **何偵察** | 北境巡邏留下的獨行偵察，刀比話多 | **戰備向**：玩家裝備斧或 SMG、或已建任一塔時更信任店家 | 佇列中站姿較挺；購買後點頭即走 | 購買 +1；`weapon !== machete` 或任一塔 >0 時再 +1 |

### 2.3 顧客流與生成規則

**原則**：不打斷既有「有貨才來客」循環；具名 NPC 是**加权插入**，不是四條獨立 AI 路線。

| 規則 | 規格 |
|---|---|
| 匿名底流 | 維持現有 cooldown（約 2.2s 級）與單一服務通道（本階段不擴多櫃檯） |
| 具名權重 | 每次 `spawnCustomer` 時，若 `displayedMeat > 0`，以機率表決定「匿名／某一常客」 |
| 初值權重（示意） | 匿名 55%；老周 12%；林護理 12%；小包 11%；何偵察 10%（總 100%） |
| 好感微調 | 該常客好感 ≥ 中階時，自身權重 +3%～+5%（從匿名池扣除），讓「熟客更常來」 |
| 同時在場 | 仍僅 1 位顧客 actor；具名以換皮／換名牌呈現 |
| 夜襲中 | 不生成顧客（與現況一致） |
| 缺貨 | 不生成；具名也不例外 |

**身份顯示**

- 到店時 Toast 或頭頂名牌：`老周 · 廢鐵收購`（3 秒淡出）。
- 匿名顧客不顯示名字（或顯示「過路人」）。

### 2.4 好感階與獎勵

**好感上限**：每位常客 **0–10**（整數）。

| 階 | 好感 | 解鎖獎勵（一次性） | 獎勵 ID | 數值 |
|---|---:|---|---|---|
| 初識 | 0–2 | — | — | — |
| 面熟 | 3 | 小額現金 | `aff_{id}_3` | ✦ 40 |
| 常客 | 6 | 經營小加成（永久，本存檔） | `aff_{id}_6` | 見下表 |
| 摯友 | 10 | 較大現金 + 徽記字串 | `aff_{id}_10` | ✦ 120 + unlock 旗標 |

**常客階（6）永久小加成（每位不同，避免同質）**

| 常客 | 常客階加成 | 說明 |
|---|---|---|
| 老周 | 肉品交易 +1 金／筆 | 與老闆娘 % 加成可並存；先算 % 再 +1，或固定 +1 於入帳後（實作取「先 base+員工+牧場，再主角%，再好感 flat」） |
| 林護理 | 壁壘受擊時 8% 機率減免 1 點傷害 | 低機率減傷，不讓壁壘無敵 |
| 小包 | 每次賣肉 5% 機率「多付 5 金小費」 | 獨立於收銀員 +5 結構 |
| 何偵察 | 玩家武器傷害 +0（改為）清波獎金 +5 | 強化戰備敘事，不與狙擊手 +1 傷直接疊爆；若需更直觀可改「擊殺賞金 +1」——**建議採擊殺賞金 +1**（行屍 2→3 等） |

> **定案建議**：何偵察常客階＝**所有擊殺賞金 +1**（含玩家與塔擊殺入帳）。摯友階仍以現金為主。

**摯友徽記（解鎖字串，供 HUD／結算展示）**

| 常客 | unlock 字串 | 顯示名 |
|---|---|---|
| 老周 | `friend-lao-zhou` | 廢鐵之友 |
| 林護理 | `friend-nurse-lin` | 夜班燈火 |
| 小包 | `friend-kid-bao` | 雪屋守護 |
| 何偵察 | `friend-scout-he` | 北境眼線 |

**獲取節奏上限（防刷）**

- 同一常客：**每個白天／每波整備期最多 +2 好感**（含偏好加成）。
- 全常客合計：單一日循環不另設硬頂（因單通道顧客流已自然限速）。
- 獎勵節點只領一次，寫入 `customerRewardsClaimed`。

### 2.5 入帳疊加順序（規劃，避免實作歧義）

```
base = 20
base += cashierLevel >= 1 ? 5 : 0
base += pasture2 ? 5 : 0
base += lao_zhou_bonus_active ? 1 : 0   // 好感階 6+
if protagonist === butcher_matron: base = floor(base * 1.10)
if kid_bao_tip_proc: base += 5
credit(base)
```

### 2.6 UI

- 整備面板新增「常客」小頁或手冊下方摺疊：「四位常客好感條」。
- 好感條：0–10 格；達 3／6／10 時短暫金光（尊重 reduced-motion）。
- 未解鎖獎勵以鎖顯示條件提示（例：「再來訪約 2 次」——可用模糊提示，不強制精確）。

### 2.7 驗收條件（實作後）

1. 四位常客名稱、偏好文案、到店可辨識（模型或名牌至少一項）。
2. 好感只在合法購買時增加，且遵守每波上限。
3. 3／6／10 獎勵各領一次，重整不重複。
4. 缺貨、夜襲中不出現常客。
5. 匿名顧客流仍可支撐 Ch5 第一筆交易教學。

## 3. 員工升級線（各 2 級）

### 3.1 總則

| 項目 | 規格 |
|---|---|
| 員工 | `hunter` 獵人、`cashier` 收銀員、`dog` 牧羊犬 |
| 等級 | `0` 未雇用 → 雇用後 `1` → 升級 `2`（**上限 2**） |
| 雇用解鎖 | 仍為手冊 **第 6 章** 後可雇（與 `SHOP_UNLOCK_CHAPTER.employeeShop` 一致） |
| 升級解鎖 | 建議 **第 12 章**「無人也能運轉」完成後開放升級（強調全自動後的精煉）；若節奏偏慢可改第 10 章——**定案：Ch12 後開放升級** |
| 夜襲中 | 不可雇用、不可升級 |
| 價格顯示 | Lv0→1 顯示雇用價；已 Lv1 顯示「升級 Lv2 · ✦ N」；Lv2 顯示「已滿級」 |

### 3.2 數值表

#### 獵人 `hunter`

| 等級 | 解鎖方式 | 價格 | 行為 |
|---:|---|---:|---|
| 0 | — | — | 無 |
| 1 | 雇用 | **140**（現況） | 尋路牧場、對牛 **1 傷／1.45s**（對齊現況） |
| 2 | 升級 | **120** | 攻速提升：**1 傷／1.10s**；移動略快 2.15→2.40；可選：攻擊動畫更乾脆 |

**設計意圖**：縮短「等獵人砍牛」的空窗，強化牧場 AFK 鏈前端。

#### 收銀員 `cashier`

| 等級 | 解鎖方式 | 價格 | 行為 |
|---:|---|---:|---|
| 0 | — | — | 結帳 1.15s、無 +5 |
| 1 | 雇用 | **190**（現況） | 結帳 **0.38s**、肉價 **+5** |
| 2 | 升級 | **150** | 結帳 **0.28s**；肉價改為 **+8**（取代 +5，非再 +8）；顧客離場 cooldown 2.2→**1.9s**（僅當有 Lv2 收銀時） |

**設計意圖**：吞吐 + 單價雙提升，回報經營投資；+8 與老闆娘 %、老周 +1 可並存但需在 UI 寫清「小費／加價」。

#### 牧羊犬 `dog`

| 等級 | 解鎖方式 | 價格 | 行為 |
|---:|---|---:|---|
| 0 | — | — | 無 |
| 1 | 雇用 | **230**（現況） | 拾取地面肉並搬回攤位陳列（現況） |
| 2 | 升級 | **160** | **優先拾取剩餘壽命最短的肉**（對齊 ROADMAP）；搬運速度 +20%；一次可銜 **2** 份（若場上 ≥2，路徑中第二份在半径 2.5m 內順路撿） |

**設計意圖**：減少肉品過期浪費感，閉環「獵人砍 → 犬撿 → 收銀賣」。

### 3.3 升級總成本參考

| 員工 | 雇 + 升 | 合計 |
|---|---:|---:|
| 獵人 | 140 + 120 | **260** |

## 8. 總結

本設計在不推翻 15 章／30 波骨架的前提下，用三刀切入角色厚度：

1. **開局選擇**（老闆娘／狙擊手／少年）決定經濟、單挑或防線節奏，並寫入存檔 v3。
